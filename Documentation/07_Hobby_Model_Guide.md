# 07 - Hobby Model Guide & Schema Mapping

## 1. What is the `Hobby` Model?
The **`Hobby`** model represents personal interests, activities, or hobbies (such as Photography, Chess, Coding, Mountain Climbing) associated with a user's account.

Similar to `SocialLink`, a user has a **1-to-Many relationship** with hobbies: one user account can have multiple hobbies.

---

## 2. SQL Schema Mapping
This model maps directly to the **`dbo.Hobbies`** table defined in `01_Schema.sql`:

| C# Property | C# Type | SQL Column | SQL Data Type | Description / Notes |
| :--- | :--- | :--- | :--- | :--- |
| `HobbyID` | `int` | `HobbyID` | `INT IDENTITY(1,1)` | Primary Key (auto-generated by SQL) |
| `UserID` | `int` | `UserID` | `INT` | Foreign Key to `dbo.Users.UserID` |
| `HobbyName` | `string` | `HobbyName` | `NVARCHAR(100)` | Name of the hobby (e.g., 'Photography') |
| `HobbyDescription`| `string` | `HobbyDescription`| `NVARCHAR(MAX) NULL` | Optional detailed description or notes |
| `CreatedAt` | `DateTime` | `CreatedAt` | `DATETIME2` | Timestamp when the hobby was added |

### Step 3: Sample Code-Behind Implementation (`ManageHobbies.aspx.cs`)
How to bundle form inputs into the `Hobby` model:

```csharp
using System;
using System.Web.UI;
using _241611JalopPersonalWebsite.Model;

namespace _241611JalopPersonalWebsite.User
{
    public partial class ManageHobbies : Page
    {
        protected void Page_Load(object sender, EventArgs e)
        {
            if (Session["UserID"] == null)
            {
                Response.Redirect("Login.aspx");
                return;
            }
        }

        protected void btnAddHobby_Click(object sender, EventArgs e)
        {
            // 1. Get logged-in user ID
            int currentUserId = Convert.ToInt32(Session["UserID"]);

            // 2. Validate
            string hobbyName = txtHobbyName.Text.Trim();
            if (string.IsNullOrEmpty(hobbyName))
            {
                lblStatus.Text = "Please provide a hobby name.";
                return;
            }

            // 3. Bundle into Hobby model
            Hobby newHobby = new Hobby
            {
                UserID = currentUserId,
                HobbyName = hobbyName,
                HobbyDescription = txtDescription.Text.Trim()
            };

            // 4. Pass model to repository (e.g. HobbyRepository.Create(newHobby, out string error))
        }
    }
}
```
