# Administrator Content Editing Guide & Architecture

## Overview
This document details the architectural implementation allowing Administrators to edit any user's portfolio content (profile, bio, avatar, education, skills, affiliations, hobbies, and social links) directly from the Admin Dashboard or when viewing a user's portfolio.

---

## 1. Security Architecture & Authorization

### Privilege Escalation Prevention
- **Strict Role Verification**: Non-admin users are strictly forbidden from editing other users' portfolios. If an unprivileged user accesses `Onboarding.aspx?u={token}` or `Onboarding.aspx?userId={id}`, the page verifies `Session["Role"] == "Admin"`.
  - If the logged-in user is not an Admin, the query string target is discarded, and the page only displays and modifies the logged-in user's own profile (`Session["UserID"]`).
- **Session Preservation**: When an Administrator modifies another user's profile, the system ensures the Administrator's own authentication session (`Session["FirstName"]`, `Session["LastName"]`, `Session["FullName"]`, `Session["UserID"]`) is **not** overwritten with the target user's details.
- **Obfuscated Tokens**: All links passing user identifiers between pages utilize the AES-encrypted and Base64-URL-safe token generated by [`UrlObfuscator.cs`](file:///c:/Martin%20Archive/Programming/ASP%20NET/241611JalopPersonalWebsite/241611JalopPersonalWebsite/Backend/Common/UrlObfuscator.cs).

---

## 2. Admin Entry Points

Administrators have three distinct pathways to edit any user's content:

1. **User Management Table (`Frontend/Admin/Dashboard.aspx`)**:
   - Each row has an **"Edit Content"** button that navigates directly to:
     ```
     ~/Frontend/User/Onboarding.aspx?u={encryptedToken}
     ```
2. **User Summary Modal (`Frontend/Admin/Dashboard.aspx`)**:
   - In the modal drawer (`pnlUserSummaryModal`), an **"Edit Content"** button (`lnkSummaryEditPortfolio`) opens the target user's onboarding editor in a new or current tab.
3. **Live Portfolio Top Bar (`Frontend/User/Portfolio.aspx`)**:
   - When an Administrator views another user's live portfolio (`Portfolio.aspx?u={encryptedToken}`), an **"Edit Content"** button appears in the top navigation bar, linking to `Onboarding.aspx?u={encryptedToken}`.
   - The user menu's "Edit Portfolio" link also resolves dynamically to the target user's profile token.

---

## 3. UI/UX Administrative Experience

When an Administrator is editing another user's profile in `Onboarding.aspx`:
- **Admin Alert Banner**: A neo-brutalist yellow banner displays at the top:
  ```
  ADMIN EDITING MODE: You are currently modifying the portfolio content for [Target User's Full Name].
  [Return to Admin Dashboard]
  ```
- **Dynamic Page Titles**:
  - The page heading becomes: `Edit Portfolio: [Target User's Full Name]`
  - The subtitle informs the admin: `You are editing this user's live portfolio information with Administrator authority.`
- **Smart Redirection**:
  - Upon clicking **"Save & Exit"**, the confirmation message reads:
    `User portfolio successfully updated! Redirecting to portfolio preview...`
  - The browser automatically redirects to that user's live portfolio: `Portfolio.aspx?u={encryptedToken}`.
