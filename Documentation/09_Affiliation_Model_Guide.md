# 09 - Affiliation Model Guide & Schema Mapping

## 1. What is the `Affiliation` Model?
The **`Affiliation`** model represents a user's memberships, organizations, clubs, student councils, volunteer work, or professional affiliations.

Similar to `Hobby` and `SocialLink`, a user has a **1-to-Many relationship** with affiliations: one user account can have multiple organizations and leadership positions.

---

## 2. SQL Schema Mapping
This model maps directly to the **`dbo.Affiliations`** table created in `02_Alter_Profile_Affiliations_SocialLinks.sql`:

| C# Property | C# Type | SQL Column | SQL Data Type | Description / Notes |
| :--- | :--- | :--- | :--- | :--- |
| `AffiliationID` | `int` | `AffiliationID` | `INT IDENTITY(1,1)` | Primary Key (auto-generated by SQL) |
| `UserID` | `int` | `UserID` | `INT` | Foreign Key to `dbo.Users.UserID` |
| `OrganizationName` | `string` | `OrganizationName` | `NVARCHAR(150)` | Name of organization or club (e.g. 'Computer Society') |
| `Position` | `string` | `Position` | `NVARCHAR(100)` | Role/Title (e.g. 'President', 'Member', 'Lead Developer') |
| `StartYear` | `string` | `StartYear` | `NVARCHAR(10)` | Starting year (e.g. '2021') |
| `EndYear` | `string` | `EndYear` | `NVARCHAR(10) NULL` | Ending year (e.g. '2024' or 'Present') |
| `CreatedAt` | `DateTime` | `CreatedAt` | `DATETIME2` | Timestamp when the record was added |

### Step 3: Sample Code-Behind Implementation (`ManageAffiliations.aspx.cs`)
How to bundle form inputs into the `Affiliation` model:

```csharp
using System;
using System.Web.UI;
using _241611JalopPersonalWebsite.Model;

namespace _241611JalopPersonalWebsite.User
{
    public partial class ManageAffiliations : Page
    {
        protected void Page_Load(object sender, EventArgs e)
        {
            if (Session["UserID"] == null)
            {
                Response.Redirect("Login.aspx");
                return;
            }
        }

        protected void btnAddAffiliation_Click(object sender, EventArgs e)
        {
            int currentUserId = Convert.ToInt32(Session["UserID"]);

            // Validate required inputs
            string org = txtOrgName.Text.Trim();
            string position = txtPosition.Text.Trim();
            string startYear = txtStartYear.Text.Trim();
            string endYear = string.IsNullOrWhiteSpace(txtEndYear.Text) ? "Present" : txtEndYear.Text.Trim();

            if (string.IsNullOrEmpty(org) || string.IsNullOrEmpty(position) || string.IsNullOrEmpty(startYear))
            {
                lblStatus.Text = "Please fill in Organization Name, Position, and Start Year.";
                return;
            }

            // Bundle into Affiliation model
            Affiliation newAffiliation = new Affiliation
            {
                UserID = currentUserId,
                OrganizationName = org,
                Position = position,
                StartYear = startYear,
                EndYear = endYear
            };

            // Pass model to repository (e.g. AffiliationRepository.Create(newAffiliation, out string error))
        }
    }
}
```
