# 05 - SocialLink Model Guide & Schema Mapping

## 1. What is the `SocialLink` Model?
The **`SocialLink`** model represents external web and social media links (such as GitHub, LinkedIn, Facebook, personal blogs, or external portfolios) associated with a user's account.

Unlike `UserProfile` (which has a 1-to-1 relationship with a user), `SocialLink` has a **1-to-Many relationship**: a single user can have multiple social links.

---

## 2. SQL Schema Mapping
This model maps directly to the **`dbo.SocialLinks`** table created in `02_Alter_Profile_Affiliations_SocialLinks.sql`:

| C# Property | C# Type | SQL Column | SQL Data Type | Description / Notes |
| :--- | :--- | :--- | :--- | :--- |
| `SocialLinkID` | `int` | `SocialLinkID` | `INT IDENTITY(1,1)` | Primary Key (auto-generated by SQL) |
| `UserID` | `int` | `UserID` | `INT` | Foreign Key to `dbo.Users.UserID` |
| `SocialLinkName` | `string` | `SocialLinkName` | `NVARCHAR(50)` | Platform name (e.g., 'GitHub', 'LinkedIn') |
| `Link` | `string` | `Link` | `NVARCHAR(500)` | URL (e.g., 'https://github.com/username') |
| `CreatedAt` | `DateTime` | `CreatedAt` | `DATETIME2` | Date/time when link was added |

## 4. Entire Code Snippet for `SocialLink.cs`

File: `241611JalopPersonalWebsite/Model/SocialLink.cs`

```csharp
using System;

namespace _241611JalopPersonalWebsite.Model
{
    /// <summary>
    /// Model class representing social media and external links (e.g., GitHub, LinkedIn).
    /// Maps directly to the dbo.SocialLinks table in the database.
    /// </summary>
    public class SocialLink
    {
        // Primary Key from dbo.SocialLinks
        public int SocialLinkID { get; set; }

        // Foreign Key referencing dbo.Users.UserID
        public int UserID { get; set; }

        // Platform / Network Name (e.g., 'GitHub', 'LinkedIn', 'Facebook', 'Portfolio')
        public string SocialLinkName { get; set; }

        // The URL string (e.g., 'https://github.com/username')
        public string Link { get; set; }

        // Timestamp when link was added
        public DateTime CreatedAt { get; set; }
    }
}
```

### Step 3: Sample Code-Behind Implementation (`ManageSocialLinks.aspx.cs`)
How to bundle form values into the `SocialLink` model:

```csharp
using System;
using System.Web.UI;
using _241611JalopPersonalWebsite.Model;

namespace _241611JalopPersonalWebsite.User
{
    public partial class ManageSocialLinks : Page
    {
        protected void Page_Load(object sender, EventArgs e)
        {
            if (Session["UserID"] == null)
            {
                Response.Redirect("Login.aspx");
                return;
            }
        }

        protected void btnAddLink_Click(object sender, EventArgs e)
        {
            // 1. Get logged-in user ID
            int currentUserId = Convert.ToInt32(Session["UserID"]);

            // 2. Validate input
            string url = txtLinkUrl.Text.Trim();
            if (string.IsNullOrEmpty(url))
            {
                lblStatus.Text = "Please enter a valid URL.";
                return;
            }

            // Ensure URL starts with http:// or https://
            if (!url.StartsWith("http://") && !url.StartsWith("https://"))
            {
                url = "https://" + url;
            }

            // 3. Bundle into SocialLink model
            SocialLink newLink = new SocialLink
            {
                UserID = currentUserId,
                SocialLinkName = ddlPlatform.SelectedValue,
                Link = url
            };

            // 4. Pass model to repository (e.g. SocialLinkRepository.Create(newLink, out string error))
        }
    }
}
```
