# 11 - Education Model Guide & Schema Mapping

## 1. What is the `Education` Model?
The **`Education`** model represents an academic degree, diploma, course, or school background (e.g., "BS in Information Technology" at "University of Santo Tomas") associated with a user's account.

Similar to `Affiliation` and `Hobby`, a user has a **1-to-Many relationship** with education records: a user can list high school, undergraduate, and postgraduate degrees.

---

## 2. SQL Schema Mapping
This model maps directly to the **`dbo.Educations`** table defined in `01_Schema.sql`:

| C# Property | C# Type | SQL Column | SQL Data Type | Description / Notes |
| :--- | :--- | :--- | :--- | :--- |
| `EducationID` | `int` | `EducationID` | `INT IDENTITY(1,1)` | Primary Key (auto-generated by SQL) |
| `UserID` | `int` | `UserID` | `INT` | Foreign Key to `dbo.Users.UserID` |
| `CourseName` | `string` | `CourseName` | `NVARCHAR(150)` | Degree, Strand, or Program (e.g. 'BS in Computer Science') |
| `University` | `string` | `University` | `NVARCHAR(150)` | School, College, or University name |
| `StartYear` | `string` | `StartYear` | `NVARCHAR(10)` | Starting year (e.g. '2020') |
| `EndYear` | `string` | `EndYear` | `NVARCHAR(10) NULL` | Graduation year or 'Present' |
| `CreatedAt` | `DateTime` | `CreatedAt` | `DATETIME2` | Timestamp when the record was added |

### Step 3: Sample Code-Behind Implementation (`ManageEducation.aspx.cs`)
How to bundle form inputs into the `Education` model:

```csharp
using System;
using System.Web.UI;
using _241611JalopPersonalWebsite.Model;

namespace _241611JalopPersonalWebsite.User
{
    public partial class ManageEducation : Page
    {
        protected void Page_Load(object sender, EventArgs e)
        {
            if (Session["UserID"] == null)
            {
                Response.Redirect("Login.aspx");
                return;
            }
        }

        protected void btnAddEducation_Click(object sender, EventArgs e)
        {
            int currentUserId = Convert.ToInt32(Session["UserID"]);

            string course = txtCourseName.Text.Trim();
            string school = txtUniversity.Text.Trim();
            string startYear = txtStartYear.Text.Trim();
            string endYear = string.IsNullOrWhiteSpace(txtEndYear.Text) ? "Present" : txtEndYear.Text.Trim();

            if (string.IsNullOrEmpty(course) || string.IsNullOrEmpty(school) || string.IsNullOrEmpty(startYear))
            {
                lblStatus.Text = "Course Name, University, and Start Year are required.";
                return;
            }

            // Bundle into Education model
            Education newEducation = new Education
            {
                UserID = currentUserId,
                CourseName = course,
                University = school,
                StartYear = startYear,
                EndYear = endYear
            };

            // Pass model to repository (e.g. EducationRepository.Create(newEducation, out string error))
        }
    }
}
```
